## Weather dashboard

The dashboard uses `ny_noaa` from the `p8105.datasets` package to explore daily
temperatures at station **USC00300055** during **2010**. Three interactive Plotly
charts show monthly mean temperatures, the relationship between daily minima
and maxima, and the distribution of daily maxima within each month. All
temperatures are expressed in degrees Celsius.
